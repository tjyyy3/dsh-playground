# 0.6.0-beta.1

插件发布到 npm，包名从 `@playground/dsh-playground` 改为 `dsh-playground`。

- 在 DSH 第三方插件安装框填入 `dsh-playground@beta` 即可安装测试版。GitHub
  仓库地址仍可作为备用安装来源。
- DSH 不会更新第三方 npm 插件。版本卡对 npm 来源提示先卸载再重新安装，并可复制
  `dsh-playground@beta` 或 `dsh-playground`。
- 发布 GitHub Release 后，CI 通过 npm trusted publishing 发布同一 commit。

从旧版迁移：先在 DSH 插件页卸载旧插件，再安装 `dsh-playground@beta`，不要同时保留
两个插件。不要用旧版本卡里的“复制 Git spec”覆盖安装，那样会新增一个插件而不替换旧
插件。旧包名下保存的插件配置不会迁移，改过 API 地址、CLI 路径或 `releaseChannel`
的用户需要重新设置。Playground 登录不受影响。

声明的 DSH 最低版本仍为 0.2.1-rc.5。真实 DSH 中的 npm 安装、卸载重装和迁移尚未验证。
