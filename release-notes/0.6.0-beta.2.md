# 0.6.0-beta.2

- 刷新目录时，从官网更新玻尔 AI 产品周赛、大科学装置专项赛和科学骑士大师赛北大专区已公布的赛程。读取失败时显示提示，并保留上次成功读取的赛程或内置赛程。
- 提交统计仅计入当前登录账号在对应赛题中的提交，按北京时间统计当日记录并按提交编号去重。平台未提供配额标记时显示配额占用未知。
- 主控关联子任务时使用当前配置的平台，不再要求传入 `base_url`。已记录的历史关联仍保留原平台和赛题信息。
- DSH 开启开发者工具并提供轨迹视图时，Playground 主控面板可切换对话和轨迹。从工具记录打开轨迹会定位到对应调用。
- npm 来源的版本卡会检查 GitHub Release 对应的精确 npm 版本及公开安装包。两者就绪后才显示升级、卸载重装说明和可复制的 npm spec。
- npm 版本或安装包返回 404 时显示尚未就绪，网络错误和超时提示重试。再次检查会立即重查 npm；GitHub 发布列表仍缓存三分钟。
- 打开版本卡不访问 npm。检查不发送 Playground 凭据，不下载安装包内容。Git、本地链接和本地文件来源保持原有行为。

声明的 DSH 最低版本仍为 0.2.1-rc.5。离线行为测试和打包检查不代表真实 DSH 的安装与更新流程已经验证。
