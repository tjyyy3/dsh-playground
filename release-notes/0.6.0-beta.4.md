# 0.6.0-beta.4

## 中文

- 打开 Playground 主控或返回窗口时，工作台会检查所选渠道。发现兼容的新版本后，可从顶栏进入版本卡。支持升级的 DSH 会在你点击「立即更新」后安装指定版本，按提示重启即可继续原来的对话。
- 在连接设置中可以关闭自动检查。检查遇到临时网络故障或安装包还在同步时，工作台会稍后重试。Git 安装用户手动检查后也能看到已核实的更新提示。
- 手动重装提示仅在确有可升级版本且当前宿主需要手动操作时出现。已装好新版但尚未重启时，卡片提示重启。
- 从 beta.3 的 npm 安装升级到本版，请在 DSH 插件页移除旧版，再安装 `dsh-playground@0.6.0-beta.4`。如大陆镜像尚未同步，请选择 npm 官方源。更新渠道默认为 stable，可在插件配置中将 `releaseChannel` 设为 `beta` 以接收后续测试版。

## English

- The workbench checks your selected channel when you open the controller or return to the window. A toolbar notice opens the version panel. On supported DSH hosts, choose **Update now** to install the exact compatible release and restart when prompted to continue your conversation.
- You can turn automatic checks off in connection settings. A temporary network failure or a package still propagating gets a shorter retry interval. Manual checks on Git installations now show verified updates in the toolbar.
- Manual reinstall instructions appear only when an upgrade is available and the host requires manual installation. If the new version is already on disk, the panel prompts you to restart.
- To upgrade an npm installation from beta.3, remove the old version in DSH and install `dsh-playground@0.6.0-beta.4`. Select the official npm registry if your mirror is still syncing. Set `releaseChannel` to `beta` in the plugin configuration for future previews. The default channel is stable.
