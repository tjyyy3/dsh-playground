# 0.6.0-beta.3

## 中文

- 首次打开主控可查看仍在进行的比赛和赛期，按截止时间排序。后续进入时会检查新赛事、独立专题和新赛期。支持「明天再提醒」、确认本批和关闭全部提醒。
- 工作台支持中英文，默认跟随 DSH，也可以在登录状态左边单独切换。安装包附带两份 README。
- 主控可以自行给原生 DSH 子智能体分工，在同一个可继续的子对话中回答问题、补查缺项并收回结果。工作区侧栏还可以查看本地 Codex 对话及最近回复，向已加载的目标对话发送追问。
- 赛题目录和主控查询支持官网提供的赛道、分类和分期，修复了翻页和自定义学科筛选的问题。

## English

- The controller shows ongoing competitions and rounds on first use, with the nearest deadline first. Later visits check for new contests, standalone event pages and rounds. Snooze a batch until tomorrow, acknowledge it, or turn alerts off.
- The workbench follows the DSH interface language and supports a local Chinese or English override. Both README files ship with the package.
- The controller can delegate work to native DSH children and continue the same child chat to answer questions or request missing checks. The workspace sidebar can also summarize local Codex chats and send follow-ups to an available original thread.
- Browse official tracks, groups and rounds in supported competitions. Pagination and custom discipline selection now preserve the selected filters.
