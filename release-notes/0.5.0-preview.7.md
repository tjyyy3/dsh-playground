# 0.5.0-preview.7

- Hand plugin installation and updates to the DSH plugin manager.
- Check stable or beta releases only after a workbench button click.
- Show install source, running and on-disk versions, and the Release's pinned Git spec.
- The workbench sends submission requests to the task's existing Agent and tracks official attempt IDs.

The declared DSH floor is 0.2.1-rc.5, matching the inspected desktop runtime
and its installed @deepseek-ai/dsh-sdk-protocol package. Earlier host versions
have not been qualified. Live installation, update, refresh, rebuild, and
restart behavior still require verification.

This version predates the beta.N release policy. The next prerelease must rank
above 0.5.0-preview.7, for example 0.5.1-beta.1. The release workflow rejects
publishing this preview tag under the new policy.
