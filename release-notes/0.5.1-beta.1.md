# 0.5.1-beta.1

First beta under the `beta.N` release policy.

- DSH owns installation and updates. The read-only version card shows the
  install source, running and on-disk versions, and copies the Release's
  pinned Git spec.
- Release checks run only after a click, with separate timeout, failure and
  rate-limit messages.
- The workbench groups controller tasks by challenge and sends submission
  requests to each task's existing Agent.

The declared DSH floor is 0.2.1-rc.5. Live installation, update, refresh,
rebuild and restart behavior has not been verified in a real DSH host.
