# 0.6.0

## 中文

Playground 工作台的首个正式版采用已验收的 0.6.0-beta.4 功能代码。工作台支持中英文、赛事提醒、主控派工和版本检查。

- 在 DSH 第三方插件安装框输入 `dsh-playground` 安装正式版。旧的 beta.3 npm 安装需先移除，再安装 `dsh-playground@0.6.0`。
- 使用 beta.4 的用户可以从版本卡检查正式版。支持升级的 DSH 会在点击「立即更新」后安装，按提示重启。旧宿主可使用卡片给出的手动安装方式。
- 默认渠道 stable 只提示正式版。想提前试用新功能，可以将插件配置 `releaseChannel` 设为 `beta`。

## English

The first stable release of Playground Workbench uses the verified 0.6.0-beta.4 application code. It includes a bilingual workbench, competition alerts, controller delegation and update checks.

- Enter `dsh-playground` in the DSH third-party plugin installer for stable releases. To upgrade an npm installation from beta.3, remove the old plugin and install `dsh-playground@0.6.0`.
- On beta.4, check the version panel for the stable release. On supported DSH hosts, choose **Update now** and restart when prompted. Older hosts show manual instructions.
- The default stable channel offers stable releases. Set `releaseChannel` to `beta` in the plugin settings to include future previews.
